# 实验二 公平比较：第二批（fair_ctrl_v2_batch2，seeds 1–5）

执行日期：2026-10-22。协议：`docs/2、公平比较.md` 修订版 + 第二批预登记（本次运行前写入 `results/fair_ctrl_v2_batch2/`）。

训练配方沿用第一批 v2 的等预算调参结果（CNN lr 8e-4 / batch 64 / 监控验证 AUROC / patience 20；ET 500 棵 / max_features 32 / leaf 3），冻结后用于全部矩阵行。第一批单种子结果见 `docs/实验二-公平比较-第一批结果.md`。

**预登记要点**：种子 `[1,2,3,4,5]`；21 张表中的 P0–P6、S0–S5、F0–F7、W0 全部执行；交互只做「滤波 × 去均值」2×2；验证集保留 12–16 且**不用于任何泛化声明**；bootstrap 2000 次、患者级整患者抽样、所有对照共用同一次抽样、种子 `20261022`、95% 百分位区间。

## 1. 一句话结论

五种子跑完后，**只有 3 个对照的 95% 区间不含 0**：手工特征优于无损展平（F1−F0）、z-score 伤害 CNN、带通滤波对 ET 有小幅正效应。其余全部跨 0，包括「CNN 是否优于 ET」——因为测试集只有 **6 位患者**。

| 项 | 结果 |

## 5. 能说与不能说

**可以报告（区间不含 0）：**

1. 132 维手工特征比同一张量的无损展平对 ET 更有利，+0.0265（[+0.0002, +0.0849]）。这是本批唯一「方向为正在患者重抽样下也站得住」的正向结果，但区间下界只有 0.0002，只能谨慎表述为「可能略有帮助」；它的稳定性主要来自种子维度（sd 0.0019）。
2. 训练集 z-score 对 CNN 有害，−0.0349（[−0.1795, −0.0026]）。区间上界几乎贴 0、宽度 0.18，只能说方向为负，不能说幅度。
3. 带通滤波对 ET 有很小的正效应，+0.0070（[+0.0019, +0.0150]）；对 CNN 无分辨力（[−0.0048, +0.0096]）。
4. 传感器表里唯一区间不含 0 的一项：**S2 相对 S1 加双踝加速度计，对 ET 是小幅负效应**，−0.0086（[−0.0198, −0.0032]）。其余通道增量（背部、腕部、四部位）全部跨 0。

**不能报告：**

1. **不能说 CNN 优于 ET**。参考条件下的差值 +0.0926 区间为 [−0.0398, +0.3356]。测试集只有 6 位患者，整患者重抽样时一次抽到 5 位难度相似的患者，差值就能从 +0.09 掉到负值。第一批单种子说的「CNN 明显更好」在这批数据上不成立为统计结论。
2. 不能说「四部位信息对 ET 有增益」。点估计 +0.0795 很大，但区间 [−0.0317, +0.3091] 跨 0；原因是患者间方差极大，不是效应不存在。
3. 不能说平滑有效（CNN +0.0166，[−0.0265, +0.0378]）。
4. 不能说缺失掩码、线性插值、去均值有任何可分辨作用。
5. 不能把 F 表的结论外推到 CNN。

## 6. 与第一批的差异，以及种子方差

| 项 | 第一批（seed=1） | 第二批（5 种子均值） |
|---|---:|---:|
| M CNN | 0.9230 | 0.9107 ± 0.0178 |
| M ET | 0.8187 | 0.8180 ± 0.0008 |
| P1 CNN | 0.9260 | 0.9160 ± 0.0205 |
| S5 ET | 0.8982 | 0.8975 ± 0.0011 |
| P6 CNN | 0.9373 | 0.9273 ± 0.0148 |
| F1 ET | 0.9232 | 0.9240 ± 0.0009 |

**CNN 的种子标准差（均值 0.0136，最大 0.0205）是 ET（均值 0.0010）的约 13 倍。** 第一批的 CNN 数字正好落在这条波动带的上沿（0.9230 对 5 种子均值 0.9107，高出 0.7 个标准差），单次运行不能代表配方水平。ET 几乎不受种子影响，因为 500 棵树的投票把随机性压掉了。

这条差异对后续所有 CNN 结论都有约束：任何小于约 0.03 的 CNN 差值，在单种子下都不可信。

## 7. 限制

1. **6 位测试患者是硬约束**。患者级 bootstrap 只能重抽这 6 个人，区间宽度由患者异质性决定，不是运行次数能改善的。要收窄区间只能增加患者或改用交叉验证。
2. 验证集（12–16）三用：CNN 早停、配方选择、阈值选择。验证列不用于任何泛化声明。
3. 测试集 17–22 在历史开发中反复查看，仍属内部探索性比较。
4. 配方为第一批调参后冻结的值；调参本身搜索面是平的（见第一批报告第 2 节），因此「当前配置」不代表最优超参数。
5. 交互只检验了「滤波 × 去均值」；「填补 × 掩码」未检验，已在 `bootstrap_protocol.json` 中声明。
6. AUPRC 未做区间：sklearn 的 AP 在 2000×5×36 次调用下过慢，只报告种子均值与标准差。
7. 平滑是离线操作（使用未来窗口），不代表实时可用。

## 8. 复现

```
# 第二批（22 个实验 × 5 种子，约 45 分钟）
python -m src.fair_v2.run --all --seeds 1,2,3,4,5 --per-seed --device cuda \
  --out results/fair_ctrl_v2_batch2 \
  --cfg-json results/fair_ctrl_v2_tuned/tuning/selected_config.json

# 一致性审计（180 次运行）
python -m src.fair_v2.verify_batch --root results/fair_ctrl_v2_batch2

# 患者级配对 bootstrap 2000 次（约 3 分钟）
python -m src.fair_v2.bootstrap --root results/fair_ctrl_v2_batch2 --seeds 1,2,3,4,5

# 多种子聚合
python -m src.fair_v2.report_batch2 --root results/fair_ctrl_v2_batch2
```
