# 2、公平比较：模型对照、数据处理与特征消融

创建日期：2026-10-21；按最新研究目标修订：2026-10-22。本文替代上一版“完整方案优先”的主实验设计。

状态：实验设计文档，尚未实现或执行新协议。原代码、原始数据与已有复现结果保持不变。后续特征提取、训练和推理由用户亲自运行，助手负责讲解、协助实现和核对产物。

工程目录为“背景材料/fogstar_final_engineering/”；本文的 src/、data/、configs/、results/ 均相对该目录。

## 2.1 本次修订的目标与原则

### 2.1.1 要回答的三个问题

1. **模型效应**：数据、预处理、输入信息和评价规则一致时，CNN 与极端随机树（ExtraTrees，以下简称 ET）的表现有什么不同？
2. **数据处理效应**：固定输入、模型和其余配置，只改变一个处理模块时，两个模型的表现分别如何变化？
3. **特征效应**：固定数据处理及模型，改变传感器输入或手工特征组时，增加/移除这些信息带来多少条件性收益？

本版不再把“CNN＋单踝原始信号”与“ET＋双踝手工特征＋全身协调＋专属平滑”的差值当作模型效应。该比较只能作为完整方案的补充结果。

### 2.1.2 最新要求对旧版约定的覆盖

| 旧版安排 | 本版调整 |
|---|---|
| 主要比较完整 CNN 与 ACTE 方案 | 主实验改为相同输入信息下的 CNN 与 ET；完整方案移到补充表 |
| 只要求共同窗口，允许 ACTE 使用额外邻居平滑 | 主实验不平滑；平滑消融对两模型使用同一函数、同一上下文窗口和同一分段规则 |
| CNN 无类别权重，ET 使用 balanced | 主实验使用同一训练样本权重；权重策略改变单列消融 |
| CNN 原始时序与 ET 的 72 维手工特征直接比较 | 增加“同一时序数组：CNN 原形状／ET 无损展平”的受控模型对照 |
| 主要消融协调特征和平滑 | 分别建立预处理、传感器输入、手工特征组实验矩阵 |
| 仅对齐样本，其他数据处理保留模型专属实现 | 建立共享处理产物；模型分支不再重复滤波、划窗、填补或归一化 |

保留的约定：FoG-STAR 为首个成果数据；原版保留；先审计再冻结；训练/验证/测试按患者隔离；用户亲自训练；先单种子验收再做多种子与统计分析。

上述调整来自用户最新请求，覆盖此前 Q1“完整方案优先”和 Q5“ACTE 可使用额外平滑上下文”的主实验安排。旧方案不是新受控实验已经完成的证据。

### 2.1.3 一组差值必须对应一个明确问题

每个对照应列明：保持不变的条件、唯一主动改变的因素、指标差值及可支持的结论。

- CNN 与 ET 在同一输入上的差值：该输入和既定训练方案下的模型家族表现差异。
- 同模型滤波开/关：其他条件不变时的滤波效应。
- 同模型、同处理、增加一个传感器组：该传感器信息在当前模型结构下的增量。
- ET 全特征与去掉某组特征：该特征组在其余特征存在时的条件性作用。
- 完整方案之间同时改变多个因素：只能描述总体效果，不能归因于其中某一项。

不同模块的效应可能存在交互，不能把各次删组差值相加，当作总提升的唯一分解。

## 2.3 所有主实验共享的数据底座

### 2.3.1 数据版本、患者和标签

- 固定同一份 FoG-STAR v3 原始 CSV，保留来源、MD5、SHA-256。
- 固定 train=1–11、val=12–16、test=17–22。临床表不拼入模型输入。
- 同一患者的全部记录只能属于一个集合；不随机按重叠窗口划分训练与测试。
- 每窗 120 点、步长 30 点；尾部不足 120 点不补窗。
- FoG 标签要求有效且为 0/1。120 点中阳性数量大于 60 则 y=1；平票归 0。
- activity 真值仅供离线分层，不作为这两种模型的推理输入。
- 其他临床诊断、PD/健康分类、提前预测不属于本阶段目标。

### 2.3.2 连续记录与窗口身份

先核实 timestamp 单位、原始顺序、重复时间、倒序和间断；根据采集依据及无标签时间统计冻结连续片段规则。不能根据测试分数选择间断阈值。

每窗至少保存：

| 类别 | 字段 |
|---|---|
| 来源 | dataset_hash、protocol_id、window_id |
| 记录 | subjectID、sessionID、taskID、segment_id |
| 位置 | start_sample、end_sample、原始 CSV 起止行、原始起止时间戳 |
| 规则 | fs、窗口长度、步长、标签规则版本 |
| 标签与分层 | y、阳性采样点数、activity |
| 有效性 | 原始观测掩码、缺失比例、eligible、exclude_reason |
| 划分 | train/val/test |

window_id 在删窗前生成，能回到原始采样范围；明确行号起点和右边界是否包含。不同表示通过 ID 关联，不能按缓存行号、标签顺序或长度猜测配对。

### 2.3.3 主实验使用固定窗口总体

本版主实验不再由“CNN 是否能直接接收 NaN”决定删窗，因为后续两模型使用同一缺失修复后的输入。

统一窗口总体 W 的建议有效性规则：

1. 采集片段、标签和窗口长度合法；
2. 不跨患者、场次、任务和真实连续片段边界；
3. 在本次预登记的全部 24 路候选信号中，窗口至少存在一个有效原始观测；全部通道、全部时刻均无观测的窗口统一排除并计数；
4. 部分通道或部分时刻缺失的窗口保留，按相同规则处理后供两模型使用。

W 一旦生成，模型比较、预处理消融、传感器输入消融和手工特征消融均使用其相同 train/val/test ID。输入较少的组即使所选通道在某窗全缺失，也按预定填补规则生成输入，不单独删窗以获得更容易的测试集。

这评价的是固定可用记录总体下的模型与模块作用。若要排除缺失影响，可另在“四部位全部完整”的固定子集上重复相关成对实验；该子集内两模型和各变体仍用相同 ID，不拿完整子集与全量总体的指标差称为模块增益。

原始缺失模式和每组观测覆盖必须报告。若审计表明上述总体不适合采集条件，应先调整所有实验共享的有效性规则并冻结，不为某个模型单独筛选。

### 2.3.4 唯一共享的信号处理顺序

同一处理配置只生成一份共享产物。CNN 与 ET 必须读取它的不同形状视图，不各自重做处理。

~~~text
原始数据与原始观测掩码
  → 按真实连续记录分段
  → 可选带通滤波：各通道连续有效片段内进行
  → 统一窗口清单：120点、步长30点
  → 可选逐窗逐通道去均值
  → 可选训练集拟合的逐通道标准化
  → 统一缺失值修复
  → 保存有限值信号张量 T、原始观测掩码 M 和窗口ID
  → CNN视图 / ET视图 / 固定的手工特征派生
~~~

约束：

- 滤波不跨记录和缺失片段。短有效片段采用统一且已记录的规则；不能一分支跳过滤波、另一分支插值后再滤波。
- 均值只使用本窗口有效观测。全缺失通道的去均值量置为既定默认值并记录，不读取其他患者。
- 标准化只在训练患者的有效观测拟合，验证/测试复用训练统计量。标准差为零或训练通道全缺失时有统一回退规则。
- 不能一分支按窗口归一化、另一分支按患者归一化，也不能分别调用结果不同的缩放器。
- 原始缺失掩码始终保留，不能在填补后把人工值标为观测值。
- Inf 按非有限缺失处理，不能静默变成巨大有限数后喂入模型。
- 处理错误导致某变体输出非有限值时，修复实现或报告该实验失败；不能只删除该变体的异常测试窗。
- 模型分支不再私自滤波、去均值、插值、标准化或改变窗口标签。

## 2.4 相同输入信息下的 CNN 与 ET 主比较

### 2.4.1 共同输入与适配方式

对指定传感器集合 C，共享输入为 T，形状 N×120×C。

| 模型 | 实际接收的视图 | 信息是否相同 |
|---|---|---|
| CNN | N×120×C；网络内部按卷积要求转置 | 是 |
| ET | 按固定时间/通道顺序展平为 N×(120C) | 是，展平是无损重排 |

例如左踝 gyro 输入：CNN 为 120×3，ET 为 360 维；四部位输入：CNN 为 120×24，ET 为 2880 维。两者来自同一个数组，逐窗反向 reshape 必须还原完全相同的 T。

这组实验不对 ET 额外提取 STD、频域或协调特征，也不额外给某模型缺失提示、相邻窗口或平滑结果。

“同一输入”是信息和数值相同，不强求两个模型的接口形状相同。

### 2.4.2 模型内在差异与结论范围

允许不同的是模型本身：卷积结构与树结构、优化器与树拟合、必要的模型正则，以及 CNN 的验证早停。CNN 输入通道变化只调整必要的输入层，其余结构规则固定，记录参数数量。

本实验可描述“在此输入、预算和训练规则下的模型表现”，不能由一套固定参数证明某模型在所有数据上都更优。

原 OfficialCNN 结构可配置 in_ch，但原 paper_baseline 入口写死三个通道；现有 ET 入口只消费手工特征。相同输入比较的入口尚需实现，不是重跑旧命令即可得到。

## 2.5 数据处理模块消融：对两个模型同步进行

### 2.5.1 统一参考配置 P_ref

以下为新协议的建议起始配置，实施前写入配置冻结；它不是原版已运行结果：

| 项目 | P_ref |
|---|---|
| 输入传感器 | S0：左踝三轴 gyro |
| 滤波 | 0.5–20 Hz、四阶 Butterworth 零相位滤波 |
| 去均值 | 开，逐窗口、逐通道，仅用有效观测 |
| 标准化 | 关 |
| 缺失修复 | 在去均值/可选标准化后，缺失位置填 0 |
| 额外缺失提示 | 关 |
| 概率平滑 | 关 |
| 训练样本权重 | 两模型使用同一训练集计算的 balanced 样本权重 |
| 窗口与划分 | 固定 W 和患者划分 |

滤波和插值均按离线处理解释。零填充是在当前处理坐标中填 0，不能一边填原始物理 0、一边填标准化后 0。

### 2.5.2 一次只改变一项的实验表

每一行均分别运行 CNN 和 ET；输入 T 的来源、窗口总体、训练权重和模型参数与 P_ref 保持一致，只有表中的目标因素变化。

| 编号 | 相对 P_ref 的唯一改变 | 回答的问题 |
|---|---|---|
| P0 | 无 | 共享参考 |
| P1 | 关闭带通滤波 | 当前模型下滤波的作用 |
| P2 | 关闭逐窗去均值 | 保留/移除直流分量的作用 |
| P3 | 开启训练集拟合的逐通道 z-score | 统一缩放的作用 |
| P4 | 零填补改为预定义的窗内线性插值 | 两种缺失修复策略的差异 |
| P5 | 为两个模型同时追加原始观测掩码 | 缺失位置提示的作用 |
| P6 | 为两个模型同时应用同一七窗平滑器 | 共享后处理的作用 |

P4 不改变滤波、划窗、去均值或标准化顺序。插值只用同窗同通道的有效点，边缘按最近有效点延伸，全缺失通道回退 0；属于离线策略。缺失模式不变，不因插值成功与否重新选测试窗。

P5 中 CNN 接收按通道拼接的 [T,M]，ET 接收其同一数组的展平视图。M 为原始有效观测标志，不能仅给 ET 缺失比例而不给 CNN 对等信息。输入维度变化是该提示信息模块的必要变化，需记录模型参数量。

P6 复用 P0 的已训练模型和未平滑预测，不重新训练；两模型使用完全相同的上下文 ID、分段、窗口顺序、k=7、边缘归一化和居中模式。两个模型分别在各自平滑后的验证概率上重新选阈值。

### 2.5.3 类别权重作为独立训练策略

主比较先对齐权重。若研究类别平衡，再增加 W0：两模型同时改为统一样本权重 1，其余条件保持 P_ref。

报告这是训练权重策略效应，不与滤波等信号处理混称。CNN 无权重、ET balanced 的结果不能作为受控主比较。

### 2.5.4 处理交互

上述单项消融给出的是参考背景下的条件效应。如果滤波与去均值、填补与掩码可能互相影响，应预登记对应 2×2 组合，固定其余条件，并对两个模型同时执行。

不能把“关闭 A”和“关闭 B”的单项差值相加，推断同时关闭 A、B 的结果；只有实际运行组合实验才能讨论该交互。

## 2.6 传感器输入与手工特征消融

### 2.6.1 原始传感器输入：CNN、ET 都做

固定 P_ref 的处理规则、W、划分、权重与模型超参数，只改变从同一共享 T 中选取的通道；每行两个模型取得相同信息。

| 编号 | 通道集合 | 维度 C | 合法对照解释 |
|---|---|---:|---|
| S0 | 左踝 gyro | 3 | 参考输入 |
| S1 | 双踝 gyro | 6 | 对 S0：增加右踝 gyro |
| S2 | 双踝 acc＋gyro | 12 | 对 S1：增加双踝 acc |
| S3 | S2＋背部 acc/gyro | 18 | 对 S2：背部信息增量 |
| S4 | S2＋腕部 acc/gyro | 18 | 对 S2：腕部信息增量 |
| S5 | 四部位 acc＋gyro | 24 | 对 S2：背部与腕部联合增量；可与 S3/S4分析交互 |

每一行内部的 CNN−ET 才是该输入条件下的模型差异。S0 的 CNN 与 S5 的 ET 差值不能当作模型差异。

各组不能按所用传感器分别删除缺失窗口。窗口总体和原始观测掩码固定；同一填补策略用于各通道。另报各输入组的真实观测覆盖，尤其是所选通道全缺失的窗口数量。

### 2.6.2 手工特征组：固定 ET 做表征消融

固定 S5 四部位的共享处理张量、W、训练权重、ET 参数和评价规则。所有特征从同一个 T 和 M 派生，不再独立滤波/去均值。

完整特征 F_full 采用当前代码的 132 维定义：

- STD 24 维；
- RMS 24 维；
- 相邻差分绝对值均值 24 维；
- 对数冻结指数 24 维；
- 原始缺失比例 24 维；
- 四部位加速度/角速度模长两两相关性 12 维。

固定频带、FFT、分母稳定项、常量/全缺失通道处理与特征顺序。特征值无效时修复统一定义，不按特征组各自删样本。

| 编号 | 输入 ET 的内容 | 目的 |
|---|---|---|
| F0 | 同一 S5 张量无损展平，2880 维 | 直接时序输入参考，可复用同配置的 S5 ET |
| F1 | F_full，132 维 | 与 F0 比较手工表征转换的作用 |
| F2 | F_full 去掉 STD＋RMS，84 维 | 幅值特征组的条件性贡献 |
| F3 | F_full 去掉差分特征，108 维 | 动态变化特征贡献 |
| F4 | F_full 去掉冻结指数，108 维 | 频域比例特征贡献 |
| F5 | F_full 去掉缺失比例，108 维 | 缺失比例提示贡献 |
| F6 | F_full 去掉协调相关性，120 维 | 已有四部位局部信息基础上的协调特征贡献 |
| F7 | 现有 ACTE 的 72 维选择 | 与 F1 比较踝部主导特征选择策略 |

F2–F7 主要与 F1 成对比较，不采用先加 A、再加 B、最后加 C 的顺序累计结果来宣称每组的唯一独立贡献。必要时再做预登记的特征组合交互。

去均值后的 STD 与 RMS 可能高度冗余，应先核对数值关系；本版先把二者作为一个幅值组，不把近似重复的两项都写成独立创新。

对协调特征的主要消融是 F1 对 F6：两者已经包含四部位局部特征，便于判断额外协调编码的作用。仅比较“双踝局部 60 维”与“60＋协调12维”，还同时引入背部/腕部信息，不能单独证明协调公式本身的贡献。

### 2.6.3 不把不等价输入强行叫作同输入模型比较

F 表回答的是“这些表征对 ET 的作用”，不能直接外推成对 CNN 同样有效。

不得把 132 个无自然时间顺序的统计特征当成 132 个时间点，直接喂给原一维时序 CNN，并宣称这仍是原结构的公平比较。

若后续确实要验证手工特征对 CNN 的增量，需要另立固定融合结构的实验，明确新模型、信息和容量控制；不混入本次默认主矩阵。当前 CNN 的输入贡献由 S 表和 P5 的匹配信息实验回答。

## 2.7 训练、权重、参数选择与阈值

### 2.7.1 同训练样本和验证使用范围

- 所有组在固定 W 的 1–11 号患者训练窗口更新参数；CNN 不再只用其中 60%。
- CNN 在 12–16 号共同验证患者上选最佳轮次和早停，不使用训练患者内部随机窗口作“独立验证”。
- ET 使用同一训练窗口拟合。ET 没有 epoch，不能要求两模型具有相同训练轮数。
- 数据变换的拟合仅用训练观测；验证用于预先允许的早停、模型配置选择和阈值，测试只评价。
- CNN 选择最佳轮次的监控量、最小改善、patience、最大轮数全部预登记；各消融固定不变。

### 2.7.2 完全一致的训练样本权重

在相同训练 ID 上，根据训练标签计算：

~~~text
w_c = N_train / (2 × N_train,c)
~~~

同一个窗口的权重在两模型完全相同。CNN 使用逐样本 BCEWithLogitsLoss 乘对应权重后按批次均值聚合；ET 使用同一 sample_weight，class_weight 设为 None，避免双重加权。不得只给一边做过采样或类别平衡。

若固定的是统一权重策略而实际实现不同，须先通过每个 window_id 的权重向量核对，不能仅凭参数名都写 balanced 通过验收。

CNN 的梯度训练与树的分裂准则属于模型内在差异，不强求损失函数形式相同。

### 2.7.3 超参数与调参预算

受控消融中，每个模型在参考条件下确定一套参数后冻结；不为某个特征组、滤波版本或传感器组单独调参，再把收益归因于该模块。

ET 的 max_features 特别需要控制：输入维度变化时，固定比例会改变每次分裂的候选特征数量。本版受控矩阵建议使用固定整数 **max_features=16**，计划中的手工特征最小组也大于 16；500 棵树、min_samples_leaf=3 可作起始配置。它是新控制协议的建议参数，不是现有 0.5 比例配置的原样复现，也不预设为最优。

若实施前统一调整该整数，相关实验均使用同一确定值；不得对低维组临时截断、对高维组另用比例。增加更低维新特征组时，先重新登记可比的参数规则。

CNN 保留参考结构，除必要输入通道外其余层结构和训练超参数固定。原有 L2 和 AdamW 权重衰减必须分别记录，不能在某个消融中无意关闭。

单套固定参数的主表结论限定为“此配置下的效果”。若要比较两模型经过合理优化后的效果，再增加**单独的等预算验证集调参实验**：

1. 两模型预先登记搜索空间、相同配置尝试数量和随机种子；
2. 原则上不在两个模型上使用完全相同的参数数值，而是给予相同规则的选择机会；
3. 以相同验证主指标选配置，不看测试分数；记录训练时间、算力和实际尝试数；
4. 优化后的模型表与固定参数的模块归因表分开，不用单边精调结果证明模型家族优劣。

具体搜索预算须在实施前登记；当前不自动安排大规模搜索，也不把未经等预算校准的结果称为两模型可达到的最优能力。

### 2.7.4 随机性、推理与阈值

第一批 seed=1；第二批 seeds=[1,2,3,4,5]，在查看新结果前登记。相同种子列表便于配对，不代表两个模型的随机过程相同。

保存环境版本、设备、线程数、确定性设置、训练时间。CNN 推理使用 eval/no_grad，加载最佳权重；不读取待预测 FoG 或 activity 真值。

每个模型、输入/处理配置、种子、平滑版本，均单独用自己的共同验证概率选择阈值：

- AUROC 为主指标；
- 阈值按 0–1、步长 0.001 搜索，使敏感度与特异度的绝对差最小，并列取最小阈值；
- p≥阈值判阳性；
- 测试阈值固定，不能使用 test_eer 作为主口径；
- 某验证集合只有一种标签时报告协议异常，不从测试标签补阈值。

不同组阈值数值可以不同。平滑组在平滑验证概率上重新选阈值，F1 等差值应解释为该处理加既定阈值规则的效果；AUROC/AUPRC 可帮助区分不依赖阈值的变化。

## 2.8 平滑与上下文的共同规则

主模型、预处理和特征比较默认无平滑。研究平滑时才开启 P6，并同时作用于两个模型。

1. 两模型在同一 W 上产生概率，使用同一上下文 ID；
2. 按 subject/session/task/segment 和真实窗口起点排序；
3. 窗口缺口和真实采样间断均断开，不按删窗后的数组位置压紧；
4. k=7、居中模式、边缘按实际可用邻居归一化，两模型完全一致；
5. 短于七窗的输出长度必须正确，不能直接依赖旧 np.convolve 的短序列行为；
6. 保存 p_raw、p_eval、上下文 ID/哈希和各版本阈值；
7. 不重新训练后再比较平滑开关；模型权重必须相同。

本版撤销主比较中 ACTE 可独享额外邻居的安排。若额外做“ACTE 全候选上下文”实验，只能列为独立的完整方案扩展，不用于证明模型或平滑算法本身的纯贡献。

所有默认平滑、插值和零相位滤波按离线分析报告。只加 causal 平滑参数不能证明整条链路实时。

## 2.9 实验矩阵与分批实施

### 2.9.1 第一批：先验收可执行性

固定 seed=1，先完成：

1. M：P_ref、S0 的 CNN 与 ET 同信息主对照；
2. P1：滤波开/关，两模型同步，用来验收预处理单因素控制；
3. S5：四部位时序输入，两模型同步，用来验收通道选择与无损展平；
4. F1 与 F6：同 S5、同处理、同 ET 参数，验收完整特征与去协调特征的对照；
5. P6：复用参考模型预测，对两个模型施加同一平滑器；
6. 保存/加载、窗口配对、权重配对、处理产物一致性和指标复算全部通过。

这批检查覆盖模型、处理、传感器、手工特征及后处理五类操作。已有相同配置和输入哈希的模型/预测可以复用，不能为开关平滑重复训练。

第一批是流程与设计验收，不以超过原历史 0.932 为条件，也不提前宣称模块稳定有效。

### 2.9.2 第二批：完整消融与统计

按已预登记计划完成 P、S、F 表的五种子实验，以及患者级配对 bootstrap 2000 次。W0 类别权重策略和有明确假设的交互实验在配置中列明是否纳入，不能结果出来后只补有利组合。

若实现工作量或训练预算不足，先缩减并冻结要检验的模块范围，明确未检验项；不能仍声称已经得到全部模块贡献。不默认运行所有因素的笛卡尔积。

若协议、输入、模型和环境未变，复用第一批 seed=1 的对应结果。第二批不能按第一批测试分数决定是否执行；发现真实数据或实现错误则记录、修复并建立新协议版本。

## 2.11 指标、贡献定义与统计报告

### 2.11.1 指标和成对差值

报告 AUROC、AUPRC、F1、敏感度、特异度、precision、accuracy、混淆矩阵、窗口数、阳性比例及观测覆盖。AUROC/AUPRC 用概率，其余用验证阈值。

对越高越好的指标，预先约定差值方向：

- 模型差异：CNN − ET，条件相同；
- 模块加入效应：开启 − 关闭；
- 策略替换效应：新策略 − 参考策略；
- 特征组贡献：全组 − 去掉该组；
- 模型×模块交互：(CNN开启−CNN关闭) − (ET开启−ET关闭)。

同时给出两边绝对指标，不能只给正差值。负贡献也完整报告。

P、S、F 表可共享模型/数据，但不是所有表格行都互为合法对照。原 CNN 与原 ACTE 的总体差值不纳入这些归因公式。

特征组有相关性，删组后保留特征也可能补偿；该贡献是此数据和背景配置下的性能差，不是唯一因果归因或医学机制。树内置重要性或解释图不能替代这些控制实验。

### 2.11.2 稳定性与不确定性

- 各种子分别计算，再报告均值和样本标准差；不把五次概率平均成集成后冒充五种子均值。
- 成对差值使用相同种子列表及共同患者/窗口；种子波动不等于患者泛化区间。
- 第二批患者级配对 bootstrap 固定尝试 2000 次，每次整患者有放回抽样，所有对照用同一患者抽样。
- 缺少两类时该次 AUROC 不可定义，记录并报告有效次数；区间方法、水平与 bootstrap 种子预先登记。
- 分患者 AUROC 仅对同时有两类者定义，报告有效患者数量；单类不填 0 或 1。
- 当前固定测试集仅来自原定 6 位患者且已在历史开发中多次查看，仍属于内部探索性比较。更多运行或 bootstrap 不会使其变成新独立测试。
