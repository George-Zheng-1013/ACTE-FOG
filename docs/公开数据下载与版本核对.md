## 3. 本地数据初查

- sensor：329027 行、31 列；clinical：22 行、10 列；subjectID 1–22，对应一致，临床表没有重复患者。
- 四部位共 24 通道及代码所需标签、分组列齐全；FoG 标签为 0/1。
- activity 实际有 0–7，0 不能擅自解释成某个正常活动；原程序处理活动多数投票时会排除 0。
- 共有 106 个 subject/session/task 分组，sessionID 出现 1/2/3。
- 按原代码 120 点窗口、30 点步长构建，得到 10599 窗，与旧缓存数量一致；本轮原版代码提取后，全部缓存数组也逐元素一致。
- 通道存在缺失，具体缺失比例见 `data_audit_20261020.json`；不能默认全部传感器始终可用。
- 组内 timestamp 差分中位数约 0.0166667，且未见非正差分。其数值在 60 Hz 下更像秒，与官方 README 的 ms 描述有疑点；这是推断，尚未据此修改原文件。
- 7 个 subject/task 组合跨多个 session；3 对相邻原始分组具有相同 subject/task、不同 session。原 ACTE 缓存不保存 session，后续须核实窗口流中的具体边界影响。

这些检查不足以证明所有数据间断、坐标系或临床标注都无问题。此次成功复现的是原始处理，不能因此跳过后续协议核对。
